# Секулярный Nightreign

Мод для ELDEN RING NIGHTREIGN 1.03.3 (русский язык): без богов, религии, магии игрока, призывов духов и ритуалов.
Плюс настраиваемое время до сужения зоны и снятое ограничение 60 кадров. Подробности — в [ПРОЧТИ.txt](ПРОЧТИ.txt).

## Установка

Скачайте установщик (архив с «Установить мод.bat»), распакуйте и запустите «Установить мод.bat».
Он скачает отсюда последнюю версию мода и установит её; если рядом лежит Seamless.zip — поставит и Seamless Co-op.
Игра тоже обновляется автоматически: если она старее 1.03.3 (под неё собран мод), установщик скачает патчи и обновит её.
Дальше запускайте игру ярлыком «Elden Ring Nightreign (секулярный мод)» на рабочем столе — он сам обновляет мод.

Можно и без установщика: скачать этот репозиторий (Code → Download ZIP), распаковать и запустить «Установить мод.bat».

Мод не содержит саму игру: нужна установленная ELDEN RING NIGHTREIGN.

## Состав

- `version.txt` — версия мода; ярлык сверяет её с установленной.
- `mod\` — файлы мода: `regulation.bin`, `dinput8.dll`, `secular_text.bin`, `secular_mute.txt`.
- `scripts\` — установка, запуск, удаление (Windows PowerShell 5.1).
