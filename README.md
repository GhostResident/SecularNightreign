# Nightreign Launcher

Launcher для Elden Ring Nightreign на Windows x64. Устанавливает SecularNightreign и обновления игры. Интерфейс работает в Tauri через WebView2, операции с файлами выполняет Rust.

## Как пользоваться

1. Запустите `Launcher.exe` и выберите папку установки или `Game`. Программа ищет `nightreign.exe`.
2. Нажмите **Проверить папку**. Версия считывается из ресурсов EXE. Если метаданные недоступны, укажите установленную версию вручную.
3. Выберите локальный пакет либо настроенное зеркало для каждого перехода. Локально можно указать папку с установщиком, сам EXE или архив ZIP/RAR. Для хотфикса подойдёт папка с извлечёнными файлами или архив.
4. Подготовьте пакеты и нажмите **Установить патчи**. Переходы до 1.3.2 идут по порядку. Хотфикс 1.3.3 появляется отдельно после 1.3.2 и копирует файлы в папку с `nightreign.exe`.

Прогресс и ошибки видны в журнале. Загруженные пакеты сохраняются в `NightreignUpdates` внутри системной папки загрузок. При ошибке копирования хотфикса программа откатывает уже сделанные замены. Установщики EXE управляют своими изменениями самостоятельно.

## Установка SecularNightreign

Проверьте папку игры, затем нажмите **Проверить обновления**, **Скачать** и **Установить** в секции мода. Версия берётся из тега релиза и записывается в `Game\secular_backup\launcher.json`. Для установки, сделанной прежним скриптом, Launcher показывает «Ручная установка».

При первой установке в папку с `nightreign.exe` Launcher распаковывает встроенный `Seamless.zip` с заменой совпадающих файлов, затем устанавливает SecularNightreign. При следующих обновлениях Launcher распаковывает только SecularNightreign. Launcher 1.1.2 учитывает Seamless, установленный через 1.1.1. Если мод был установлен через 1.1.0, его можно установить повторно, чтобы добавить Seamless Coop.

Launcher распаковывает `regulation.bin`, `dinput8.dll`, `secular_text.bin` и `secular_mute.txt` из `SecularNightreign/files/` рядом с `nightreign.exe`. Формат с `files/` в корне ZIP тоже поддерживается. Исходные `regulation.bin` и `dinput8.dll` сохраняются в `secular_backup`. Существующие копии используются при переходе с ручной установки и сохраняются при обновлении. Для установки закройте игру. Пример мода рассчитан на Nightreign 1.3.3.

## Как публиковать версии мода

1. В публичном [GhostResident/SecularNightreign](https://github.com/GhostResident/SecularNightreign/releases) откройте **Releases** → **Draft a new release**.
2. Создайте тег `sm-1` или укажите текущую версию мода в формате `sm-N` или `vX.Y.Z`.
3. Прикрепите актуальный `Launcher.exe` и архив с именем `SecularNightreign.zip` к файлам релиза. Опубликуйте обычный релиз через **Publish release**.
4. Для следующего обновления создайте новый тег, например `sm-2`, и прикрепите новый `SecularNightreign.zip` с той же структурой. `Launcher.exe` добавляйте, когда изменилась сама программа.

Launcher выбирает наибольшую версию среди обычных опубликованных релизов с загруженным файлом `SecularNightreign.zip`. Для сравнения тег `sm-N` соответствует версии `N.0.0`. Архив прикрепляется как отдельный файл релиза. [Инструкция GitHub по публикации](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository#creating-a-release)

## Зеркала

Скопируйте `.env.example` в `.env` рядом с EXE и заполните нужные адреса. Для зеркала с EXE и BIN заполните три адреса одного перехода. Части BIN объединяются в `elamigos-1.bin` рядом с установщиком. Для одного архива достаточно переменной с суффиксом `_URL`. Программа перечитывает конфигурацию при расчёте списка патчей. Ключи совпадают с ключами обновлений оригинала.

Ссылки на зеркала из оригинального EXE не удалось подтвердить. В этой сборке загрузка включается через конфигурацию. Режим Online Fix не перенесён.

Переменная `NIGHTREIGN_DOWNLOADS_DIR` позволяет указать другую папку загрузок. Относительные пути отсчитываются от папки программы.

## Сборка

Нужны Rust, инструменты сборки MSVC и Windows SDK. Для запуска нужен Microsoft Edge WebView2 Runtime. RAR распаковывает системный `tar.exe`.

Храните `assets/Seamless.zip` вместе с исходниками. Rust включает этот архив в EXE при сборке.

```powershell
cargo build --release --locked
cargo test --release --locked
```

Результат сборки находится в `target\release\launcher.exe`. Для публикации используйте имя `Launcher.exe`.

## Что было в исходном EXE

Файл `Elden.Ring.Nightreign.Updater-1.0.1.exe` содержит portable-обёртку NSIS и Electron-приложение в `resources/app.asar`. В метаданных PE и внутри ASAR записана версия 1.0.0. SHA-256 исходного файла — `3DBD8FFAFEF789CAD2555F4C7981958D5B54F5B6FF7FA5E0D5551B7EA55AD56B`.

Порядок переходов, ключи зеркал и параметры установщиков восстановлены из `main.js` и `renderer.js` внутри ASAR. Исходный EXE при разборе не запускался. [Страница исходного проекта в индексе GitHub](https://github.com/Elixir-Raj/nightreign-updater-tool)
