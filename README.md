# Секулярный Nightreign

Мод для ELDEN RING NIGHTREIGN 1.03.3 (русский язык): без богов, религии,
магии игрока, призывов духов и ритуалов. Дополнительно настраивается время до
сужения зоны и снимается ограничение 60 кадров. Подробности — в [`ПРОЧТИ.txt`](ПРОЧТИ.txt).

## Установка

1. Скачайте **`SecularNightreign.exe`** со страницы [Releases](https://github.com/GhostResident/SecularNightreign/releases).
2. Запустите файл, укажите папку игры и нажмите **«Установить / обновить»**.
3. Дальше запускайте игру ярлыком **«Elden Ring Nightreign (секулярный мод)»**.

Это один портативный EXE: Rust, GUI, ZIP-распаковщик и сетевой загрузчик
находятся внутри; WebView и Node.js не используются. Сам мод загружается из
этого репозитория. Незавершённая загрузка сохраняется и продолжается с того же
байта после повторного запуска.

Если игра старее 1.03.3, лаунчер определит версию `nightreign.exe` и применит
необходимую цепочку патчей `1.3.0 → 1.3.1 → 1.3.2 → 1.3.3`. Разделённые файлы
`elamigos-1.bin` скачиваются с докачкой и собираются автоматически. Завершённое
окно RapidCRC закрывается только после окончания проверки.

Если рядом с EXE лежит `Seamless.zip`, лаунчер также установит Seamless Co-op,
не перезаписывая существующие INI с пользовательскими настройками.

## Возможности лаунчера

- установка, обновление, проверка, восстановление и удаление мода;
- обновление поддерживаемых версий игры до 1.03.3;
- докачка по HTTP Range, ETag/If-Range, пять попыток при временных сбоях;
- SHA-256-проверка патча 1.03.3 до распаковки;
- автоматическая проверка обновления мода перед запуском;
- запуск без сети с уже установленной исправной версией;
- журнал `%LOCALAPPDATA%\SecularNightreign\launcher.log`.

Старые BAT/PowerShell-скрипты оставлены как аварийный способ ручной установки,
но для игроков рекомендуется GUI.

## Сборка

```powershell
cargo build --release --locked
```

Или запустите `build-release.ps1`. Порядок публикации и однократная загрузка
патча 1.03.3 описаны в [`RELEASING.md`](RELEASING.md).
